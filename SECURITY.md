# Sicherheitshinweise

„Sonnensystem – eine Kamerafahrt“ ist eine statische Seite: HTML, JavaScript, Bilder, Ton und Modelle, ausgeliefert über
GitHub Pages. Es gibt keinen Server-Code, keine Anmeldung, keine Datenbank und keine Cookies; die Seite sendet keine
Nutzerdaten und bindet keine fremden Dienste ein. Im Browser gespeichert wird nur die gewählte Sprache.

## Sicherheitslücke melden

Bitte nicht als öffentliches Issue, sondern vertraulich über die GitHub Security Advisories des Repos
(Reiter „Security“ → „Report a vulnerability“, `johanneswanzek/sonnensystem`). Nennen Sie betroffene Adresse oder Datei,
Schritte zum Nachstellen und, wenn bekannt, die Auswirkung. Eine Antwortzeit ist nicht zugesagt; es ist ein Einzelprojekt.

Relevant sind zum Beispiel: eingeschleuste Skripte, Abhängigkeiten mit bekannten Lücken, Anfragen an fremde Server.
